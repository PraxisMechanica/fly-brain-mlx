Select one continuous Brian2 C++ standalone run per independent trial, with observer-only streaming in blocks of at most 32 steps. Keep the frozen model, initial state, original weights, replay, numerical functions, and relative scheduling unchanged. Use three stock phase monitors: pre-threshold `v/g/not_refractory`, pre-reset `v/g/not_refractory`, and end `v/g/lastspike/not_refractory`. Pre-reset observations prevent reset from hiding a misplaced input or arrival.

Append one callback through `before_network_run` and `Network.add` after scheduled end objects. The pinned network invokes it before ticking clocks. Emit bounded monitor blocks and clear only recorded rows, monitor timestamps, and monitor-local length. Do not split the numerical run or modify neuron state, clocks, queues, stimulus cursors, weights, or pathways. Serialize Boolean values explicitly because C++ Boolean vectors are not contiguous byte arrays. Require a final partial-block frame and reject missing, omitted, reordered, or corrupted frames.

Read actual recurrent/replay pathway queues directly: offsets, ordered slot edge identifiers, actual delivery order (`all_peek`), source spikes, clock values, and advancing input counters. Never call `peek`, `advance`, `prepare`, or restore methods from the observer. Hash these actual physical representations for reference repeat evidence. Brian2 retains the just-delivered current slot until its next synaptic phase; MLX clears it at end. Normalize pending absolute due-step/edge membership separately for cross-engine checks. A reconstructed ledger is an independent expectation, not a substitute for the actual queue.

Use the unchanged bucketed MLX engine with explicit Metal streams. Collect all-neuron phase/state arrays in 32-step blocks. Each step, compare every actual queue/event entry against an independent ledger on the device and release the edge-sized comparison temporaries. Transfer per-trial check results with the phase block; retain physical queue hashes at block boundaries and the actual final queue. Do not retain queue histories: the current complete queue is 286,747,677 bytes per trial, so 256 historical queues would exceed local memory.

Inspect every neuron and phase in chronological order while spike history remains common, including the first different step's pre-threshold state. Record the earliest unchanged trajectory-budget violation, first different spike identities, actual threshold states/margins, refractory flags/clocks, stimulus bits, actual ordered due edges, weights, and reduction order. After spike divergence, continue deterministic trajectory/queue digests and finite-state checks, without requiring unforced cross-engine state closeness. Preserve raw stored representations before unit conversion.

Implementation must first qualify transparency on small networks against stock uncleared monitors and ordinary MLX traces. Include repeated queue wraps, duplicates/self edges, overlapping inputs, zero refractory, blocked arrivals, silencing, and pending final queues. Transport sizes 1, 17, and 32 plus incomplete final blocks must reconstruct identical full traces and queues. Compare generated numerical source, initialization, scheduling, and compiler flags; inject transport/state/queue faults to prove detection. Then compare the complete shortest run with uninstrumented execution and measure total concurrent memory, including the four-trial mode.

This selects a source-supported qualification design. It does not qualify observer transparency, binary transport, memory use, scientific parity, or performance.
